# Security

Use GitHub's private security reporting for this repository when enabled. Otherwise contact the repository owner privately through the channel you already use with them. Provide the commit, Forever build and minimal reproduction. Remove account names, character names, raw SavedVariables, personal details and credentials before sharing any report.

The supported code is the current development branch under review. Include the exact installed commit when reporting diagnostic behavior. The repository owner will coordinate remediation and agree on disclosure timing with the reporter.
