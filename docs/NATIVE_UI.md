Keep visual acceptance for real Forever at default and compact scales, both supported locales, empty and restricted data, hover, keyboard navigation, dragging and resizing. An addon must avoid taint, protected UI mutations and cosmetic hooks that depend on internal Blizzard panel state.

Use `/da diag ui` outside combat to construct the diagnostic shortlist in an addon-owned hidden frame and inspect results in a native panel. A successful construction is a capability observation, while a real screenshot and interaction check establish visual behavior. `/da diag export` uses a native scrolling input template for local copy. The addon-owned XML template supplies the initial size before the inherited initializer runs. Closing the report releases edit focus.
